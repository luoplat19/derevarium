# Derevarium

Особиста колекція дерев: фотографії, нотатки, бестіарій, карта й досягнення.

## Оформлення

Усі екрани використовують спільну темну тему з `lib/app_theme.dart`: фони `#051F20` і `#0B2B26`, картки `#163832` і `#235347`, акцент `#8EB69B`, текст `#DAF1DE`. Головна у стилі «Початок прогулянки» містить камеру 64 px, кількість знахідок і видів та останнє дерево. Натискання на лічильник відкриває статистику. Оформлення браузера та іконка встановленої вебпрограми також відповідають темі.

## Сховище та копії

Вебверсія зберігає колекцію локально в **IndexedDB**, окремим записом для кожного дерева. Редагування одного дерева не переписує фотографії всієї колекції. Доступний обсяг залежить від браузера та вільного місця на пристрої; його можна переглянути на головній сторінці через кнопку сховища у правому верхньому куті.

При першому відкритті оновленої версії старі записи зі `SharedPreferences` автоматично переносяться в IndexedDB. Старий ключ `trees` залишається цілим; надалі він не оновлюється. Пошкоджені записи зберігаються окремо та включаються в копії. Нові фотографії стискаються до JPEG із найдовшою стороною до 1000 пікселів; фото вже збережених дерев не змінюються.

У розділі **«Сховище та копії»**:

- **«Зберегти копію у файл»** — завантажити JSON з усіма деревами, фото й нотатками. На iPhone збережіть його у «Файли» та переконайтеся, що файл збережено.
- **«Відновити з файлу»** — вибрати копію й підтвердити додавання та оновлення записів. Дерева зі співпадінням ідентифікаторів оновлюються з файлу; інші поточні дерева залишаються. Повторний імпорт тієї самої копії не створює дублікатів.
- **«Захистити сховище»** — попросити браузер захистити дані від автоматичного очищення. Браузер може відмовити.

Дані прив’язані до браузера, пристрою та адреси сайту. Синхронізації між пристроями немає; перенести колекцію можна через файл копії. Регулярно зберігайте копії поза даними браузера. Ручне очищення даних сайту може видалити IndexedDB навіть за наявності захисту.

## Оновлення на Netlify

Виконайте з каталогу проєкту в PowerShell:

```powershell
flutter pub get
flutter build web
npx.cmd netlify-cli deploy --prod --no-build --dir=build/web --functions=netlify/functions
```

Оновлюйте **той самий сайт Netlify**, відкриваючи на телефоні попередню адресу: тоді автоматичне перенесення знайде наявні дерева. Якщо адресу змінено, потрібен файл копії для перенесення.

## Перевірка

```powershell
flutter analyze
flutter test
flutter test --platform chrome test/indexeddb_test.dart
```

Браузерні тести перевіряють збереження 500 дерев із JPEG-фотографіями обсягом понад старий ліміт localStorage, повторне відкриття бази, редагування та видалення, перенесення через копію й конфлікт запису між вкладками. Звичайні тести перевіряють міграцію, збереження після помилок, формат копій та інтерфейс редактора.
